A3 P/D 配置对照与迁移

比较两版官方 CI；以 0.30rc2 文档的启动方法为起点，给出迁移到 0.32 CI 拓扑的具体调整。

先确认这不是“同配置只升级版本”

范围：同名 Eco-Tech/DeepSeek-V4.1-Flash-w8a8 模型、两台 A3、每台 16 个逻辑设备、外部 DP、1P1D。没有比较其他 DeepSeek 型号，也没有核验两次下载的 checkpoint 内容是否相同。

0.30rc2 官方 CI · V1P：DP4 × TP4 = 16D：DP8 × TP2 = 16
0.32rc 官方 CI · V2P：DP2 × TP2 × PCP4 = 16D：DP8 × TP2 = 16
迁移必须同时调整：两端 Runner、P 的 PCP/TP/DP、launcher 设备切分、connector 两端拓扑和代理的 P endpoint 数。只把 Runner 改为 V2 或只加 PCP 参数不完整。

0.30 选用正式 tag 8fde6d4e335fe300e2b949aab0e31659cce0811d；0.32 选用 release 分支固定快照 38fb7a95f30cd7d715890cf89e3e640d7992b6d9。这与原三阶段报告的 30 分支快照/32 历史快照不同，本页是独立部署补充，不更改原报告基线。

0.32 分支文档仍声明以 0.30rc2 为验证基线，且保留已移除的 enable_dsa_cp；它和 0.32 CI 不是同一套配置。当前网页文档的 D=512/72，也不是本页目标 CI 的 D=400/32。

#!/usr/bin/env python3
"""Report-derived launcher for the documented two-node A3 1P1D topology.

Uses one process per external DP rank; PP=DCP=1 in this example.
No extra harness sp_size device dimension is configured; MoE SP is unchanged.
Dry-run checks allocation and prints commands without starting vLLM.
"""

import argparse
import json
import shlex
import subprocess
import time
from pathlib import Path


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--dp-size", type=int, required=True)
    parser.add_argument("--dp-size-local", type=int, default=-1)
    parser.add_argument("--dp-rank-start", type=int, default=0)
    parser.add_argument("--tp-size", type=int, default=1)
    parser.add_argument("--pcp-size", type=int, default=1)
    parser.add_argument("--dp-address", required=True)
    parser.add_argument("--dp-rpc-port", default="12321")
    parser.add_argument("--vllm-start-port", type=int, default=7100)
    parser.add_argument("--template", type=Path, required=True)
    parser.add_argument("--devices", help="Optional comma-separated logical device IDs")
    parser.add_argument("--dry-run", action="store_true")
    args = parser.parse_args()
    local = args.dp_size if args.dp_size_local == -1 else args.dp_size_local
    if min(args.dp_size, local, args.tp_size, args.pcp_size) < 1:
        parser.error("Parallel sizes must be positive")
    if args.dp_rank_start < 0 or args.dp_rank_start + local > args.dp_size:
        parser.error("Local DP ranks must fit in the global DP size")
    if not args.template.is_file():
        parser.error("Template file does not exist")
    width = args.tp_size * args.pcp_size
    count = local * width
    devices = args.devices.split(",") if args.devices else list(map(str, range(count)))
    if len(devices) != count or len(set(devices)) != count or any(not device.strip() for device in devices):
        parser.error("Device IDs must be unique and match local_DP * TP * PCP")
    commands = []
    for i in range(local):
        visible = ",".join(devices[i * width : (i + 1) * width])
        command = [
            "bash",
            str(args.template.resolve()),
            visible,
            str(args.vllm_start_port + i),
            str(args.dp_size),
            str(args.dp_rank_start + i),
            args.dp_address,
            str(args.dp_rpc_port),
            str(args.tp_size),
            str(args.pcp_size),
        ]
        commands.append(command)
        print(
            json.dumps(
                {
                    "dp_rank": args.dp_rank_start + i,
                    "visible_devices": visible,
                    "api_port": args.vllm_start_port + i,
                    "command": shlex.join(command),
                },
                ensure_ascii=False,
            ),
            flush=True,
        )
    if args.dry_run:
        return
    processes = []
    try:
        for command in commands:
            processes.append(subprocess.Popen(command))
        while any(process.poll() is None for process in processes):
            if any(process.poll() not in (None, 0) for process in processes):
                raise SystemExit("A DP process failed; stopping the remaining processes")
            time.sleep(0.25)
        if any(process.returncode for process in processes):
            raise SystemExit(1)
    finally:
        for process in processes:
            if process.poll() is None:
                process.terminate()
        for process in processes:
            try:
                process.wait(timeout=10)
            except subprocess.TimeoutExpired:
                process.kill()
                process.wait()


if __name__ == "__main__":
    main()

如何解释性能差异

  • P 的节点名义请求上限不变：4×16=2×32=64。各 DP 调度器预算求和则从 4×8192=32768 变为 2×8192=16384；这是预算口径，不是实际吞吐或每张卡计算量。PCP 的分布、padding 与通信另行决定执行开销。
  • PCP 是同一请求的上下文并行：长输入可能受益，短输入或低负载的通信收益比需要实测。不能仅因开 PCP4 就推断更快。
  • D 的 CI 拓扑和批处理参数未改：若 TPOT 下降，优先对照 Runner、实际图命中/回退、DSpark 接受率、请求批次及 connector 等待；不能只归因于 P 新增 PCP。
  • 两端 connector 必须同步迁移：Hybrid 与 V2 指向不同 Python 实现；元数据中的 P dp/tp 必须与真实拓扑一致，代理不能继续路由到已经不存在的 7102/7103。
  • 重现 CI 与隔离版本回归是两种实验：先复现各自受支持配置；再设计受支持的控制组，分别改变 Runner、拓扑和 connector。PCP4 不可直接强制 V1，不能把不支持的组合当成控制组。

SWA replay 不能视为本配置必然获得的收益

两份 CI 均没有显式传入 replay 开关。官方 0.30rc2 tag 的 Ascend 代码未提供本次回移的 replay 接口，不能把“回移分支默认 OFF”套用于原始官方 tag。0.32 上游默认值为 ON，但该 CI 的 D 端 recompute_scheduler_enable=true 会触发 Ascend 平台降级关闭 replay；P 端若实际启用 SP，则 decoder 裁剪也受源码 gate 限制。应查看最终配置和 warning，不将开关默认值等同于实际裁剪。

保留模型、权重校验值、采样参数、输入/输出长度、请求数、并发、请求率、预热和 prefix hit 状态；记录 TTFT、TPOT/ITL、输出吞吐、成功率、实际输出长度、接受率、KV 容量及抢占。本文没有新的性能数字。
